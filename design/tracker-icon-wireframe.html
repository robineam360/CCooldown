CCRM-45 · wireframe, round 2 — usage-tracker direction

Tracker icon options

Direction from review: drop the mascot; the icon should say "usage tracker" while the colour says Claude — a darker, burnt Claude-orange so it stands out from the Claude app's own tile. Not a plain line bar. One hard constraint carries over from CCBG-12 (Status Icon Swap): whatever ships must not read as a percentage at 16 px in the status bar — so every option here is either symmetric, complete, or an instrument rather than a level.

Background colour — burnt orange vs current

Same glyph, two grounds. The darker burnt orange (left, #A34A22) separates the app from the Claude app's brighter tile at a glance; the current accent (#C15F3C) is shown for comparison. All options below sit on the burnt orange.

The options

A · Signal steps

Three ascending rounded bars — the universal "levels" mark, read as signal, never as one bar's fill. Not a line bar: it's a stepped trio.

6:32 · three steps, instantly "levels"

At 16 px: flawless — three solid steps. Risk: resembles a cellular-signal glyph if drawn too thin; the fat rounded bars avoid that.

B · Hourglass

The 5-hour window is a timer — an hourglass says "waiting for the reset" (the literal cooldown) without any level to misread.

6:32 · the X-with-caps silhouette holds

At 16 px: the pinch silhouette survives; sand detail drops. Risk: Android's own "app paused / digital wellbeing" hourglass lives in the same neighbourhood.

C · Dial with ticks

An instrument face — ring of tick marks and a centre pivot, needle pointing straight up. Says "meter" as an object; a full symmetric tick ring has no fill state to misread.

6:32 · tick ring + pivot (needle drops)

At 16 px: the needle merges with the 12-o'clock tick, leaving a symmetric tick ring — safe. Caveat: at mid sizes the up-needle can read as "a reading of 50%"; it's the only option with any residual gauge-ness.

D · Four-window ring

Four equal arc segments — the four 5-hour windows a day holds (the app's own scheduling arithmetic). Symmetric and complete, so it can't read as progress; it reads as a shutter / segmented dial.

6:32 · four segments, gaps hold at 16 px

At 16 px: the four gaps survive as long as stroke and gap widths stay matched — shown here at the widths that hold. Closest kin to the current ring identity, so the update feels like an evolution.

Notes for whichever wins

· Background: burnt orange #A34A22 squircle (themed/monochrome layers follow the system as today). Foreground pure white for contrast at the darker ground.
· Only ic_launcher_foreground.xml / ic_launcher_monochrome.xml and the background colour resource change; the pinned notification's live meter icon is untouched.
· None of these reads as a fill level at any size — the CCBG-12 bar stays met.
