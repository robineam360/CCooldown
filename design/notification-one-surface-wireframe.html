CCBG-12 · Status Icon Swap · alternative

The one-notification alternative

Instead of owning the group, keep the app down to a single notification almost all the time, so the OS never reaches for its auto-summary. Two mechanisms do the work: long-lived conditions fold into the pinned notification's expanded panel, and one-off events get setTimeoutAfter so they clear themselves.

Which alert is which

Taken from Alerts.kt as it stands. The split is not cosmetic — it decides what folds, what expires, and what has to stay a real notification.

The last two are deliberately IMPORTANCE_HIGH — the code says so about the ping in as many words. Folding them into a silent panel would delete the interruption that is the whole point of the feature. So this approach does not close the hole completely; it closes it for every case except two rare, genuinely urgent ones.

They are not exclusive. Folding the two conditions removes the long-lived offenders whatever else happens; grouping on top would then cover the residual event and urgent cases, and because conditions no longer post separately the collapsed-group state would be rare.

The condition strip, specified

Revised after review: the strip was carrying its own type scale and a rule border, which made it read heavier than the bars it sits above. It now borrows the bar rows' two type sizes exactly and earns its separation from a tint instead of a border.

Net height per condition is about 44 dp single-line, 58 dp when the detail wraps to two — against roughly 55 dp for a bar row with a sub line. So the displacement rule stays one condition ≈ one model cap.

Settings — event alert lifetime

The timeout becomes a setting rather than a constant. "Auto" ties the alert's life to the thing it is about, which is the only option that never expires an alert while it's still true.

Still open

Panel text is drawn into a bitmap, so it ignores the system font-size setting. Two condition strips of wrapped text make that more noticeable than four short bar labels do. Not a blocker for this change — it is pre-existing — but it gets worse here.
