CCRM-45 · wireframe for approval

Mascot icon options

Replaces the closed-ring identity (CCBG-12 revision of CCRM-42 (App Icon)) with a mascot that cannot be read as a usage meter at any size — the whole failure mode CCBG-12 was about. Each option is shown as the launcher tile (96 + 48), the themed/monochrome tile, and at 16 px on a status-bar strip — the size that actually decides. One constraint up front: nothing that copies Anthropic's starburst mark or official assets — the About screen says "not affiliated" and the icon must agree with it.

Option A · The crab

Crab, claws up

A nod to the Claude Code community's crab without copying anything official. Friendly, and claws-up reads as "hold on / cooling off".

6:32 · claws survive, pincers don't

At 16 px: body + two raised arms stay readable; the pincer gaps close up, so the monochrome variant drops them and keeps plain arms.

Option B · Snoozing blob

A round creature asleep with one "z" — the literal cooldown. Maximum mascot energy; the "z" is the identity at small sizes.

6:32 · disc + z — unambiguous

At 16 px: a filled disc with a "z" — nothing else in a status bar looks like it, and a solid disc cannot read as a fill level.

Option C · Steaming mug

"Take a break while it cools." Calm, adult, still characterful — the steam gives it life without being a face.

6:32 · steam drops, handle stays

At 16 px: mug + handle read instantly; steam disappears, which is fine. Risk: a mug icon next to an actual coffee app's mug.

Option D · Snowflake

Cooldown, literally. Geometric rather than mascot — included as the control option: strongest at tiny sizes, least personality.

6:32 · six-arm star, crisp

At 16 px: branches drop to a plain six-arm star — crisp, but generic; every weather app owns this shape.

Notes that apply to all four

· The launcher background stays the Claude-orange squircle; only the foreground and monochrome layers change (ic_launcher_foreground.xml, ic_launcher_monochrome.xml).
· The pinned notification's live meter icon is untouched — this is only what appears when the launcher icon shows: home screen, app info, and the status bar in the pinned-off two-alert case.
· The About screen's large icon and the README/store shots update with it; the brochure PDF only if its cover uses the icon.
· None of these can be misread as a fill level — the CCBG-12 bar for any successor.
