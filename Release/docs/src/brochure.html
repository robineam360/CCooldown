What it does

📊Both limit windows, live5-hour session bar + 7-day bars (all models and per-model caps like Fable), with exact reset day & time for each.
📅Usage historyA scrollable bar for every 5-hour session, week by week — see how many you ran and which ones hit 100%.
📌Pinned notificationAn optional always-on, silent notification with a status-bar gauge that fills as you use your 5-hour window.
📈Burn-rate forecastA sparkline of your usage curve and a plain-words projection: "At this pace: 100% at Thu 2:40 PM — 1h 20m before the reset."
🔔Granular alertsPer-window threshold chips, reset pings set off / if-busy / always, and a per-profile mute — quiet when you want, loud when it counts.
⏱️The pacing bar"Days elapsed" sits under your weekly bars — usage behind it means headroom, ahead of it means slow down.
👥Two accounts, editablePersonal (Pro/Max) and Work (Team) as fully independent profiles — separate tabs, widgets, tiles and alerts; rename them freely.
🔐Sign in on the phoneThe same secure OAuth flow Claude Code uses, right from the phone — no computer, no copied tokens, self-renews monthly.
💾Private & backed upNo servers or telemetry; the token is Keystore-encrypted. History & settings now survive a reinstall (token excluded).

How it was made

CCooldown exists because of one recurring pain: deep in a Claude Code session, the dreaded "approaching your limit" — with no idea how close, or when the window resets. The fix was to put the answer where the eyes already are: the home screen.

Claude Code built the whole thing. It scaffolded the Android project, wrote the Kotlin/Compose app and Glance widgets, decoded the undocumented usage API, designed the alert logic — and when the OAuth token endpoint kept mysteriously rejecting the app, it ran the investigation (proxy captures, header isolation tests) that found the one-header fix and gave the app its own native sign-in.

No app-development background required — just clear asks, honest testing on a real phone, and iteration. If you pay for Claude, you already have the engineer.
